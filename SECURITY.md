# Security Policy

## Supported version

Security fixes apply to the default branch and the latest tagged release.

## Report a security issue

Use **Security → Report a vulnerability** in this repository for vulnerabilities involving the validator, GitHub Actions, dependency handling, or a disclosure that should not be public yet. Include the affected file, expected impact, and a minimal reproduction when possible.

Do not open a public issue for a vulnerability that could expose credentials, compromise a contributor, or execute untrusted code.

Broken links, inaccurate catalog claims, and ordinary data-validation errors are editorial issues rather than security vulnerabilities; report them through the structured issue forms.
